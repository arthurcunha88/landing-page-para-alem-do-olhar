# Projeto: Para Além do Olhar - Landing Page

Esta é uma landing page temática desenvolvida para a campanha de conscientização sobre a **Invisibilidade Civil** e o direito fundamental à documentação básica no Brasil. O projeto foi construído do zero como parte de um desafio técnico para o **Clube de Programação do SENAI CIMATEC**, unindo impacto social, design responsivo e funcionalidades interativas.

A página apresenta a realidade de brasileiros sem registro civil, detalha as perdas sociais envolvidas e oferece canais de apoio, com foco em uma experiência de usuário fluida e informativa.

## Como Rodar o Projeto
Este projeto é uma aplicação web estática, portanto, basta um navegador para executá-lo.
1. Clone ou baixe os arquivos deste repositório.
2. Certifique-se de que os arquivos de código e a pasta de imagens estão no mesmo diretório.
3. Abra o arquivo `index.html` no seu navegador de preferência.

---

## Organização do Código
O projeto foi estruturado seguindo boas práticas de separação de responsabilidades:

* **index.html**: O esqueleto semântico da aplicação. Utiliza tags HTML5 (como `<header>`, `<main>`, `<section>` e `<footer>`) para garantir acessibilidade e uma estrutura organizada dos componentes (Hero, Institucional, Doação, Contato, Rodapé, etc).
* **style.css**: Responsável por toda a identidade visual. O código foi desenvolvido seguindo a metodologia Mobile First, onde a estilização base foi pensada para dispositivos móveis e adaptada para desktops através de Media Queries. Utiliza Flexbox e CSS Grid para garantir um layout fluido e moderno.
* **script.js**: Responsável pela interatividade. Suas principais funcionalidades incluem:
    * **Menu Responsivo:** Controle dinâmico para abertura e fechamento do menu em dispositivos móveis.
    * **Sistema de Abas (Tabs):** Lógica que permite a troca de conteúdo na seção "Quem Somos" (Missão, Visão, Valores e Projeto) sem recarregar a página, melhorando a performance.
    * **Clipboard API:** Funcionalidade que permite ao usuário copiar a chave PIX (fictícia) com apenas um clique, oferecendo feedback visual imediato.
    * **Scroll Suave:** Navegação fluida entre as seções da página com compensação automática para o Header fixo.
